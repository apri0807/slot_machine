# slot_machine
🎰 Slot Machine Game (Python)

A fun, interactive slot machine simulation built entirely in Python.
This project demonstrates key programming concepts such as random number generation, loops, conditionals, and user input handling.

✨ Features
Deposit system to manage balance

Adjustable bet per line with min/max limits

Randomized slot machine spins with fair probability

Win detection across multiple lines

Clear payout logic based on symbol values

User-friendly console interface

🛠 Tech Stack
Python 3 (standard libraries only, no external dependencies)
